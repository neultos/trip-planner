위트립 입체 아이콘 적용 규정

이 폴더의 PNG는 UI에 직접 사용하는 이미지 자산이다. 선 아이콘으로 재해석하거나 대체하지 않는다. CSS로 도형을 다시 그리지 않는다. 이모지로 대체하지 않는다.

파일 적용표
airplane.png: 항공권 바로가기
suitcase.png: 해외숙소 바로가기 / 예약 준비 안내
accommodation.png: 국내숙소 바로가기
calendar.png: 일정 만들기 바로가기
planning.png: 일정 만들기 프로모션 배너의 오른쪽 일러스트
chat.png: 위톡 상단 안내 배너 오른쪽 일러스트
share.png: 여행 글 공유 빈 화면 일러스트

적용 크기 (CSS px)
홈 바로가기: 이미지 영역 52×52, 라벨 간격 8, 4열 균등 배치. 이미지 object-fit:contain, transform/filter 없음.
배너: planning/chat은 폭 96~120px, 높이 72~96px 내에서 원본 비율 유지. 텍스트와 최소 12px 간격.
빈 화면: share는 88×88 또는 96×96, 아래 제목 간격 16px.
PNG 자체의 투명 여백을 고려해 육안 크기를 비교한다. 더 크게 보여야 한다고 원본 비율을 늘이거나 찌그러뜨리지 않는다.
이미지에 배경 사각형, 추가 그림자, 외곽선, 강한 색상 필터를 적용하지 않는다.
장식 이미지는 alt="". 버튼 안 이미지에는 중복 대체텍스트 대신 버튼에 기능명을 제공한다. 클릭 타깃은 최소 44×44.
기존 이미지 빌드 파이프라인으로 최적화 가능하나 투명도와 색·부피감은 유지한다. PNG 원본도 보존한다.

적용 예시
<button type="button" aria-label="항공권 예약">
  <img src="/assets/wetrip/airplane.png" width="52" height="52" alt="" />
  <span>항공권</span>
</button>

중요한 구분
입체 일러스트: 본 폴더 자산을 반드시 사용한다.
기능 아이콘: 뒤로가기, 검색, 닫기, 더보기, 공유, 편집, 길찾기, 외부링크, 하단 내비게이션 등은 시안처럼 통일된 선 아이콘을 사용한다. 모든 UI 아이콘을 입체로 바꾸지 않는다.
브랜드 로고: 기존 위트립 W 심볼 원본을 사용한다. 이 묶음은 로고 교체용이 아니다. 메인만 심볼, 그 외 페이지 상단은 메뉴명.
제휴사 로고: 실제 제공자의 사용 허용 자산을 사용한다. 본 묶음에 제휴사 로고는 포함하지 않는다.
호텔·여행지 사진: 이 묶음에는 포함하지 않는다. 기존 사진 선정 규정을 따른다.

검수
390px 모바일에서 원본 시안과 비교한다. 바로가기 네 개가 모두 선 아이콘이면 적용 실패다.
이미지 경로 404, 불투명 사각 배경, 잘린 날개/핸들, 늘어난 비율이 없는지 확인한다.
이 파일과 자산을 함께 저장소에 넣고 각 사용 위치를 보고한다. 자산 로딩 실패를 선 아이콘 대체로 숨기지 않는다.

생성된 입체 자산은 시안의 분위기를 맞춘 신규 제작본으로, 기존 시안에서 픽셀 단위로 추출한 원본은 아니다.
