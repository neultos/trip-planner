위트립 메인 이미지 교체 묶음

모든 사진은 글자 없는 신규 AI 제작 이미지이며 실제 호텔 상품의 증빙 사진이 아니다. 도시별 실제 풍경의 정밀한 기록이 아니라 여행 분위기용으로 사용한다. 특정 숙소의 실제 사진처럼 표시하지 않는다.

이미지 적용 위치
destination-osaka.png / destination-taipei.png / destination-tokyo.png / destination-busan.png: 지금 떠나기 좋은 곳 4개 카드
theme-city.png / theme-relax.png / theme-food.png / theme-nature.png: 취향대로 떠나는 여행 4개 카드
banner-stay.png: 머무는 순간까지 특별하게 숙소 배너
hero-day.png / hero-night.png: 상단 메인 캐러셀 배너 (직전 가독성 개선본 유지)

사진에 글자를 굽지 않는다. 도시명·테마명·헤드라인·버튼은 기존 UI 텍스트로 배치한다.
썸네일은 object-fit:cover, 원본 종횡비 유지, 기존 카드 비율 유지. 상단 배너 컨테이너 aspect-ratio:1536/830, radius16px.
숙소 배너는 밝은 왼쪽 여백에 #081C39 제목을 배치한다. 기존 흰색 카피를 그대로 쓰지 않는다. 필요하면 왼쪽 7%, top18%, 제목20px/1.3 700, 서브11px/1.5로 설정한다. 글자 뒤 그라데이션·검정막 금지.
상단 낮 배너: 짙은 네이비 제목·서브, CTA#1244BF. 밤 배너: 흰 제목·서브·CTA. 문구는 왼쪽 하늘에만 배치하고 인물/건물과 겹치지 않게 한다.
파란 친구초대 배너와 연한 배경의 지도·카메라 일러스트 배너는 사진 자산이 아니므로 이 묶음으로 변경하지 않는다. 기존 입체 아이콘 묶음의 planning.png를 사용한다.
배포 전 360/390/430px에서 크롭·글자 대비·이미지 깨짐을 확인한다. 원본 보존, 필요한 크기의 WebP/AVIF를 별도로 만들 수 있다.
